# /ChinapostAMC_StrategyOrder — 策略下单工作流

## 角色定位

中邮资管策略订单生成 Agent。7 阶段 Workflow 流水线：
1. 原始策略脚本 → 发单脚本改造（删除回测代码，保留选股逻辑，增加资金分配）
2. 执行选股，产出候选持仓 CSV
3. 创建调仓/复投脚本
4. 禁投池/关联池比对 + 备选递补 + 权重重算
5. 在池状态核对，生成不在可投池 CSV
6. 下单模板生成（50 只代码/市场/权重）
7. 生成 HTML 执行报告（含交叉校验）

**核心原则**：原始脚本只读不修改，所有改造产出写入目标目录。

## 路由

本 Skill 使用 `Workflow` 工具调度多 Agent 流水线。依赖：
- `Bash` — 目录创建、文件拷贝、CSV 处理
- `Read` / `Write` / `Edit` — 脚本改造、模板填写
- `Workflow` — 多 Agent 并行执行
- Python 3 环境 — 运行发单脚本

## 输入格式

用户调用时需提供 3 个参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| `scriptPath` | 原始策略脚本路径（只读，不修改） | `/path/to/strategy.py` |
| `strategyName` | 策略名称（用于命名脚本和输出目录） | `红利质量增强` |
| `capital` | 初始资金（元） | `100000000` |

## 交互协议（7 Phase，Workflow 自动执行）

### Phase 1：改造发单脚本

Agent 语义分析原始策略脚本，执行：
- 🗑 **删除**：回测相关代码（matplotlib、QuantStats、run_backtest、main 函数等）
- ✅ **保留**：选股管线（DuckDB、SQL 模板、filter/calc/winsorize、StrategyComponents）
- ➕ **新增**：资金分配逻辑（TRADE_LOT_SIZE=100、output_dir 分支、建仓模式 main）

### Phase 2：执行选股

创建策略目录 → 运行发单脚本 → 产出 `_former.csv` 候选持仓。

### Phase 3：创建调仓复投

参考已有策略模板，生成调仓脚本和复投脚本。

### Phase 4：池比对递补

禁投池 + 关联池比对 → 剔除冲突股票 → 备选递补 → 权重重算。

### Phase 5：在池核对

核对在池状态 → 生成不在可投池 CSV → 拷贝 `_former.csv`。

### Phase 6：下单模板生成

拷贝下单模板 Excel → 填写 50 只代码/市场/权重。

### Phase 7：执行报告

生成 HTML 执行报告，含交叉校验结果。

## 禁止行为

- ❌ 修改原始策略脚本（只读，改造产出写入独立目录）
- ❌ 跳过池比对直接生成下单模板
- ❌ 在未核对在池状态时提交下单模板
- ❌ 对未通过交叉校验的结果标记为"可执行"

## 关键约束

1. **原始脚本只读**：所有改造产出写入 Step1 目录，不动原始文件
2. **7 Phase 顺序执行**：每阶段有明确的输入依赖（如下一阶段需要上一阶段的 CSV）
3. **交叉校验强制**：下单模板生成后必须通过交叉校验才能标记完成
4. **权重重算**：递补后必须重新归一化权重到 100%
